Enfoque Arquitectónico

3 formas de estructurar jairoromo.ai. Elige la que mejor se adapta a tu visión.

A

⭐ Monolito Modular (Recomendado)

Un solo repo Next.js. Páginas: / /sessions /vault /courses /login. Supabase maneja Auth + DB + Storage + Realtime. Stripe Webhooks en API routes. Deploy: Vercel un click.

✅ Pros

  • Un solo deploy
  • Shared components
  • Más rápido de construir

⚠️ Contras

  • Escala como un bloque
  • Bundle crece con el tiempo
B

Multi-Dominio Separado

Landing en jairoromo.ai (Astro, ultra rápido). LMS en learn.jairoromo.ai (Next.js). Auth en Supabase. Stripe en ambos.

✅ Pros

  • Landing velocidad máxima
  • LMS aislado y escalable

⚠️ Contras

  • 2 repos = 2x mantenimiento
  • Session compartida compleja
  • Más tiempo de build
C

Next.js + Backend Separado

Frontend Next.js + API Fastify separada en Railway/Fly.io. Supabase solo para Auth. PostgreSQL propio con Prisma ORM.

✅ Pros

  • API reutilizable
  • Control total de DB

⚠️ Contras

  • Más infra = más costo
  • CORS, deploy complejo
  • Overkill para fase 1
